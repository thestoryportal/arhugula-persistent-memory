## The one question

Condition C10 is OPEN and blocks the program's F1 verdict: a coined multi-word value (a made-up two-word product name, 4–6 tokens) written into Qwen2.5-3B's weights by locate-then-edit (MEMIT with an AlphaEdit null-space projector, layers 4–8) is read back on only 12 of 72 held-out paraphrases (24 subjects × 3 rephrasings the edit never saw); the best harness-side variant with the unchanged tokenizer (a stacked second edit, CORPUS/50) reaches 24/72 at a locality cost; a minted vocabulary row for the value (a different representation, CORPUS/45) reaches 34–46/72, labeled PARTIAL. Single-token and two-token real values reach 69/72. Your question: **what, in the published literature and public code, could carry a five-token coined value to held-out phrasings in-weight, on this Mac (M3 Pro, 48 GB unified memory, Apple MPS, no CUDA), under the strict held-out full-sequence bar?** Editing methods and model families both count. Side stores (WISE, GRACE, MELO, P-Tokens…) are engineering fallbacks by ruling, never a route: log them, do not rank them.

## Rules that do not bend

- **Never run an experiment.** No edits to the model, no harness runs, no `orx exp run`, no `edit.py`, no smoke solve. You design tests; the program runs them as pre-registered falsifiers. If you catch yourself thinking "a quick run would settle this", write the test into `hypotheses.md` instead.
- **Local-only.** No rented compute, no managed backends. A model that does not fit the plan's §3 prefilter (fp16 ≤ 28 GB decimal, d ≤ 5120 unless verified, band ≤ 5 layers or streamed) is a `lead` at best.
- **Leads, never evidence.** Nothing you produce goes into `CORPUS/`, the runbook, the ledgers, the hypothesis register or memory. Write only under `results/research_pass_2026-10-06/` and the OpenResearch ledger nodes — with one authorized exception: Connected Papers `.bib` exports go into the collection's `INBOX/` at `/Volumes/memit/llm-database-poc-mirror/connected-papers-knowledge-graphs/INBOX/`, as the operator's existing 117 graphs were made (name each file after the paper; never overwrite).
- **Verify before you cite.** Every arXiv id, repository and checkpoint you name is one you opened. A fetch summary is not a read; say which section you read.
- **The bar is the bar.** Held-out full-sequence recall of the coined value, with locality scored as a separate axis. A paper's "generalization" on CounterFact or zsRE real entities is not that bar; say so when you log it.
- **Do not steer the other agent.** An automated editing loop runs beside you on the GPU in a sealed folder; it is not yours to read, write or advise.

- "H-12: try AlphaEdit with a smaller λ." — already swept (CORPUS/37–39, 44); the inventory's row 7 lists the knobs that returned NULL. Build on it or skip it.
- "H-20: WISE reaches 0.98 generalization, so route through WISE." — a side store; `fallback` by ruling, and its metric is not our bar.

- A hypothesis without a cheapest test, or with a test whose pass/fail is "see if it improves".
