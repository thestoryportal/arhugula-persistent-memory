## 4. Does widening the guard change other meanings?

**Yes: the current constant is shared across three distinct rules, and the enlarged admissible reference range changes possible direction outcomes.**

### Separate reproduction, V2 comparability, and NULL labeling

`ENVELOPE` drives block-F LAW#3 (`experiments/track_c/c10u_mint2_read.py:377–379`), V2 comparability (`:418–421`), and `_single_label`'s unconditional NULL interval (`:289–293`). The prose requires “[11,18] is NULL whatever the gain” (`docs/C10U_MINT2_PREREG.md:92`). The replication branch separately hard-codes that same [11,18] exclusion (`experiments/track_c/c10u_mint2_read.py:330–335`). An assignment to line 21 is therefore not an isolated reproduction fix.

**Recommended scope:** apply A4 to **F's known-baseline reproduction**; retain V2's frozen comparability screen and the fixed [11,18] NULL rule as separately named rules. V2 has different head identities and pairing structure; the prereg expressly says matching envelopes cannot restore historical comparability (`docs/C10U_MINT2_PREREG.md:23`, `:78`). If the program instead broadens V2's screen too, preregister that as an explicit comparability-scope change, not an identical-known-baseline correction.

For individual arm labels, retaining [11,18] as NULL is conservative. Changing the constant to [5,18] happens to give the **same individual labels on admissible A4 references**: with S≥5, any candidate count 5–10 has gain at most 5 and cannot meet +10 or ≥30; 11–18 stays NULL. I verified this by comparing the actual primary label function under both lower bounds over S=5..18, binding counts −72..72, and both locality states: 4,060 comparisons, no differences. This limited equivalence does **not** establish unchanged block routing, out-of-envelope arm labels, or the hard-coded replication branch.

### Positive direction labels can now coexist with NULL seeds

Under the old admissible S≥11, a positive direction's `min(candidate) − S ≥10` forces every candidate ≥21, outside the NULL interval. With S as low as 5, that implication disappears. The reader computes directions independently of individual labels (`experiments/track_c/c10u_mint2_read.py:405–415`, `:475–481`, `:502–510`). Count-only counterexamples, conditional on clean fit/locality and matching replication:

| Block and counts | Frozen direction formula | Individual candidate labels |
|---|---|---|
| V2: S=5; M1={34,36,46}; M2={15,16,18} | SPAN-DIRECTION: 34−18=16≥10 and 15−5=10. A matched M1-48={34,36,46} clears the 48-row condition too. | NULL / NULL / NULL |
| F: S=5; M1F={40,36,41}; MO={15,25,36} | MODIFIER-RECOVERY: 15−5=10 and max(MO)=36≥min(M1F)=36. | NULL / PARTIAL / LEAD before replication suffixes |

I reproduced both with the current pure `_range_direction` and `_single_label` functions. These are **logic counterexamples, not model observations or completed valid blocks**. The V2 example matters if a global replacement also relaxes V2 comparability; it is excluded if that screen stays frozen. The F example remains relevant even to the narrower F-only correction. Merely separating the NULL constant does not fix this interaction.

**My recommended compatibility rule:** retain the unconditional NULL rule and require every candidate seed to be outside it before issuing a positive SPAN-DIRECTION or MODIFIER-RECOVERY routing label. With the positive gain condition and S≥5, this is `min(M2)>18` or `min(MO)>18`. This guard was logically redundant under the old admissible S≥11, so it preserves that domain's positive-routing behavior. It is nevertheless an explicit prospective §3 compatibility amendment, not something licensed solely by CORPUS/44. Freeze its truth table and consequence before the rerun. If the program elects to allow positive routing alongside NULL seeds instead, it must explicitly justify and report that changed interpretation; this review does not endorse silent adoption.

Apply that resolution to conditional spending as well: the current control/replication schedule follows raw direction and pending replication (`experiments/track_c/c10u_mint2_read.py:531–550`). A global gate change could otherwise trigger a control and replication for the all-NULL V2 example.

### Comparator and replication definitions remain intact if preserved explicitly

The comparator must remain the **actual same-block multi count**, not a historical point estimate, an envelope midpoint, 11, or a clamped value (`docs/C10U_MINT2_PREREG.md:92–101`; `experiments/track_c/c10u_mint2_read.py:309–327`, `:349–350`). The gain margin, LEAD threshold, seed-range comparisons and locality/write ratios need no numerical relaxation. Admission of lower reference counts can change which blocks qualify and which routing outcomes occur, so report S beside every gain.

Replication still means fresh processes using the **same frozen contexts and inits within r2**, its own in-block comparator, and matching source/material hashes. It measures process spread, not independent seed draws (`docs/C10U_MINT2_PREREG.md:78`; `experiments/track_c/c10u_mint2_read.py:279–286`, `:314–320`). New contexts belong between attempts/blocks, not between a block and its replication. The amended guard must apply consistently to both F blocks; old r1 material is not eligible.
