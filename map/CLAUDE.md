# Code map

This map covers `code/` only. Source files own behavior.
The inventory names durable kinds. The catalog routes to source.

## Walk

Find your cluster below. Open its section in [the noun index](objects/_index.md).
Find the noun. Open its owning source file. This takes two hops from this catalog.
All index rows are stubs. Read source before you change code.
Use [the map guide](CONTEXT.md) for universes. Read the inventory only for wiring evidence.

## Name collisions

Controller: NEW-1 resource control and Intel transfer control have separate owners.
Deadline / Budget: Git deadlines, MathLab budgets, and C10 budgets differ.
StateLedger: governance prototypes and the readback prototype have separate owners.
manifest.json: MathLab harvest, MathLab reproduction, and backup evidence differ.
Receipt: Intel fields belong to `code/ops/intel/memit_intel_receive.py`; the local copy belongs to `code/ops/intel/memit_intel_copy.py`. NEW-1 uses dispatch_receipt.json.
Program: LabViz Program differs from the generated program state views.
Parameters: MEMIT, ROME, fine-tune, and MEND types differ from experiment configuration files.
The index uses distinct noun names. The inventory gives the collision source citations.
