# Map guide

This shelf maps durable kinds in code. It cites the source. It does not define source behavior.

Open [the catalog](CLAUDE.md). Select one cluster. Open its section in [the noun index](objects/_index.md). Open the source for your noun. Do not read the full source tree.

## Universes

| Universe | Use |
|---|---|
| live | A binding referrer or current instruction names the source. Open it for work on that path. |
| leftover | A historical referrer or the closed-script list names the source. Touch it only within explicit scope. |
| ghost | No qualifying referrer was found, or the named target is missing. Do not treat it as a wired path. |

The [inventory](_meta/inventory.md) owns the universe evidence. A folder label does not cover all descendants. A static binding does not prove a host launch or science authority. Generated indexes do not prove wiring.

Every noun index row has status stub. This status records map maturity. It is separate from the source universe. Check the inventory if the universe matters to your task.

The catalog names collisions. The index uses distinct noun names and owner paths. A scope pattern groups many files into one durable kind. It does not make each file a separate noun.

The [schema](_meta/schema.md) owns map fields. The object and process templates hold the future card sections. Cards, process records, and an effects index come after v2. Do not create empty folders for them.

Edit the map catalog as the entry source. MAESTRO generates its twins. The existing [closed-script list](group-b-leftovers.md) remains a separate source.
