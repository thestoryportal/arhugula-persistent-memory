# Noun shelf

Open [the index](_index.md) for one noun. Open its source file. The index has one stub row per inventory noun. It has no card bodies.

Use [the catalog](../CLAUDE.md) to select a cluster. Use [the inventory](../_meta/inventory.md) for product names, family scope, source universes, and wiring evidence. Use [the schema](../_meta/schema.md) for card rules.

Clusters follow editor questions. They do not change source ownership. Do not read this shelf in full. Cards and cluster folders come after v2.
