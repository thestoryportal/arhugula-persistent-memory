Also prove any existing rejecting hook still vetoes deletion and that no persistent hooks/config are changed. Keep the brief-prescribed `push origin --delete` command, with no force or lease flag. 2. **CI evidence must identify what actually ran.** Installed `gh pr checks --json` fields omit a head SHA and classify results into buckets; bucket alone is not terminal status plus conclusion. Tests must model gh exit 8 for pending, an empty list, wrong SHA, wrong workflow, and a pass bucket with nonterminal/unsuccessful underlying state. 3. **Head guard does not atomically guard base.** Installed `gh pr merge --help` describes `--match-head-commit` as matching the PR head; it has no expected-base flag.
