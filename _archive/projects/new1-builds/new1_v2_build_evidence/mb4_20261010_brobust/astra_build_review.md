## Decision and semantics

The reviewed implementation follows this clarification; it does not retain the earlier aggregate H-COV FAIL rule. Native/float64 count disagreement is observed precision disagreement, not a certified uncertainty interval.

2. **Native identity/parity and float64 geometry are separate.** The loader divides raw moments in fp32 (tools/new1_geometry.py:138–147). There is one native SVD, then one float64 SVD of the unchanged normalized C, with native Vh released before the second call (150–163). Native U32 and its native masks are preserved; all covariance geometry bins, ties and energies use U64/s64 (165–218). The existing symmetry, SVD reconstruction, PSD reconstruction and orthogonality thresholds remain unchanged. Pnative uses only native U32 and its allowed mask (200–202), captured count/hash/four-probe checks remain (230–260, 539–543), and E32,excluded(M) <= 1e-4 remains a separate gate and persisted record (418–434). No float64 excluded-energy <= 1e-4 gate was introduced. Tests explicitly admit large float64 excluded M energy while retaining native parity, then reject a native-parity violation (tests/test_new1_geometry.py:400–436).

3. **Every integer cutoff and every required record is retained.** Counts generate the closed integer interval and the exact disagreement band without a layer special case (tools/new1_geometry.py:191–197). Cumulative band-column energies shift both allowed and excluded fractions from the nominal float64 partition, with complement validation at every cutoff (205–218). This is algebraically the same float64-ordered prefix partition at each count. M, five adapters, 20 flat-spectrum controls, 20 spectrum-matched controls, and valid M16 all retain bands/cutoffs (418–496). The persisted synthetic fixture checks all 47 records, both cutoffs and complements (tests/test_new1_geometry.py:427–433); the separate cutoff fixture checks a three-cutoff interval and hand-computed energies, and tests reverse/equal/zero/d endpoints (331–370).

4. **Robust aggregation has the required quantifier order.** Each layer must satisfy all three original margins at all its cutoffs; only then are passing layers counted. The code requires at least three such layers, and checks the exact expected cutoff set before aggregation (tools/new1_geometry.py:331–354). Different three-layer sets cannot be unioned, and a missing intermediate cutoff is INVALID. The adversarial fixtures cover those cases and the all-nominal-fail BOUNDARY-SENSITIVE case (tests/test_new1_geometry.py:380–398). H-TOP, H-RANK and H-OVERLAP retain their previous rules (tools/new1_geometry.py:355–363). Shuffle comparisons are recorded at every cutoff; the final specificity veto is conservative over each layer's eligible cutoff choices (490–495, 558). No queue action is enabled (559).

5. **BOUNDARY-SENSITIVE is durably preserved without laundering it into prediction PASS/FAIL.** Publication accepts the literal label only for H-COV, writes it into the prediction receipt, omits its Boolean prediction gate, and uses INVALID in the shared stage envelope with the literal label in the summary (tools/new1_supervisor.py:271–289). The terminal envelope is also INVALID while finding.json retains the literal prediction (390–396). Fixtures check receipt, stage summary, absence of the Boolean gate, terminal INVALID and retained finding label (tests/test_new1_supervisor.py:537–557). MathLab schema changes were unnecessary.
