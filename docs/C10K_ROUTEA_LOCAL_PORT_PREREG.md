## 1. Hypothesis (falsifiable)

> A faithful device port of the official AnyEdit algorithm modules (`AlphaEdit_ARE`, secondarily `memit_ARE`), run on Qwen2.5-3B base on the M3 Pro with the program's own covariance caches, recovers the C10 A1/A2 easy controls (held-out paraphrase full-sequence ≥ 80%) and lifts the hard A7 project-coined multi-word arm to a usable held-out read level (≥ 85%).

Two things can falsify it cheaply: the controls fail under the port (then no A7 interpretation), or A7 stays below the bar with controls passing (then this port is not a C10 rescue on this hardware).

## 3. Arms, stimuli, metrics — identical to `docs/C10_ANYEDIT_PILOT_PREREG.md`

- **Stimuli:** the 24 fictional subjects and the three arms from `experiments/track_c/c10h_anyedit_pilot.py::build_stimuli` (A1 single-token, A2 prior-coherent two-token, A7 coined-coined); canonical prompt `"The capital of {} is the city of"`; three held-out paraphrases (`PTEST`); locality prompt `"{} is described as"`. Token-alignment gate (`docs/C10_ANYEDIT_TOKEN_ALIGNMENT_GATE.md`) must pass for every item before any edit.
- **Binding metric:** held-out paraphrase full-sequence exact match `para_full` (72 trials/arm). Diagnostics: `canon_full`, `para_first`, `cond_full_given_first`, per-token teacher-forced continuation, per-layer update norms, projector null-space dims and functional ratios.
- **Locality ⟦adv-5⟧ (pre-registered bound):** (a) **unrelated real knowledge** — the 12 held-out real countries of `configs/screens/g6_screen_qwen3b.json` not used in any arm: canonical capital prompt top-1 must stay correct for **≥ 11/12** after each arm's batch edit, and mean JS-locality ≥ 95; (b) the stock `editevery` sanity item (item 0) must still generate its answer prefix after the arm edit; (c) described-as prompts on the edited fictional subjects as the within-subject bleed read (JS `locpct`, drop ≤ 5 pts), diagnostic only because a fictional subject's pre-edit distribution is near noise. A breach of (a) caps the arm at PARTIAL.
- **Recipes:** (R0) same-run local reference = the program's in-solve AlphaEdit recipe (`configs/hparams/qwen25_3b_memit_hparams.json`, band [4-8]) via `c10e_bandknob.py` with only its harness-side device sites ported (`tools/engine_patches/p8_harness_port_c10e.py`; the vendored engine is untouched, `tools/engine_fingerprint.py` PASS, and the runner's built-in LAW#5 gate runs first). **LAW#3 numbers for R0 ⟦adv-6⟧** (CORPUS/40 baseline row, pod, 2026-06-27): A1 `para_full` 93.1 (67/72), A2 97.2 (70/72), A7 12.5 (9/72), A7 `canon_full` 33.3 (8/24); CORPUS/36 (same arms, earlier run): A1 98.6, A2 98.6, A7 19.4. R0 on the M3 Pro must land A1, A2 ≥ 80 and A7 `para_full` within [5, 35]; outside → HALT (harness drift) before any ported run. R0 is run twice (the runner's candidate slot pointed at the same hparams) to read run-to-run variance on this hardware; (R1) ported `AlphaEdit_ARE`, `window_size=1` (**primary**: the only setting that yields multiple target vectors for 4–6-token A7 values); (R2) ported `AlphaEdit_ARE`, `window_size=50` (diagnostic; one window); (R3) ported `memit_ARE`, `window_size=1` (secondary diagnostic). Each recipe runs from the clean base model; batch = all 24 items of an arm in one `apply_*` call (Genesis-style), the mode the June C10 line used.
- **Order and stop rule:** stock-item sanity → R0 baseline → R1 on A1 and A2 → **only if both ≥ 80** → R1 on A7 → R2/R3 as diagnostics. If A1/A2 fail under R1: one localized launcher/data fix, rerun the same gate, then HALT with diagnostic. No A7 interpretation without passing controls.

## 4. PASS / PARTIAL / FAIL / INVALID (mechanism-lead class)

- **PASS-LEAD — `PORTED_ANYEDIT_A7_RESCUE_LEAD`:** port diff is device-only (D1); projector functional gate passes (D4); dynamic anchor agrees (D5); token alignment 72/72; R0 baseline within its LAW#3 band; R1 A1 ≥ 80 and A2 ≥ 80; **R1 A7 `para_full` ≥ 85 = ≥ 62/72 AND ≥ 20/24 items with ≥ 2 of 3 paraphrases correct ⟦adv-7⟧** and ≥ +20 pp over R0 A7; locality bound (a) and (b) hold; per-unit records emitted; `tools/experiment_gate.py check-result` accepts; advisor PROCEED or FIX-FIRST items resolved. **Licenses:** a mechanism lead for an in-weight rescue of the C10 class on this hardware; motivates a faithful follow-up (e.g. a local 3B re-implementation under LAW#5). **Does not license:** C10 closure, any claim about official AnyEdit's own numbers, Q4/CPU-serve survival of the edits.
- **PARTIAL — `PORTED_ANYEDIT_ACTIVE_NOT_RESCUED`:** controls pass; A7 improved but < 85, or locality > 5 pts worse, or stats packet incomplete.
- **FAIL — `PORTED_ANYEDIT_A7_NOT_RESCUED_UNDER_THIS_PORT` ⟦adv: the single most important fix⟧:** controls pass; A7 < 85 after the one allowed fix. **Scope of the negative, no wider than the positive:** *this port, on 3B base, fp16, with the shipped 7B-Instruct hparams transposed and untuned (`v_lr 0.5`, `clamp_norm_factor 4`, `mom2_update_weight 15000`, `nullspace_threshold 0.02`), did not rescue A7.* AnyEdit is **not** falsified by it, and the candidate is **not** declared spent: untransferred hparams explain a miss as well as the method does. The pre-registered follow-up is a bounded sensitivity pass on A7 only — `v_lr ∈ {0.1, 0.5}` × `clamp_norm_factor ∈ {0.75, 4}` × `nullspace_threshold ∈ {0.005, 0.02}` (8 cells, ≈ 3 h) — after which "spent on local hardware" becomes an operator decision with the sweep in hand, not an automatic consequence of this run.
- **HALTED — `CONTROLS_NOT_RECOVERED`:** R1 A1/A2 < 80 after one fix; A7 diagnostic-only.
- **INVALID:** port diff contains non-device changes; projector dims ≈ 0; alignment fails; aggregate-only output; A7 interpreted before controls; hparams differ from §2 D3.

## 5. Confounders and controls

| Confounder | Fakes | Control |
|---|---|---|
| Port changes the algorithm | a "rescue" from a different method | D1 diff review; `vram_patches_applied: false`; no solver/projector edits |
| Degenerate projector (June's raw-accumulator bug) | AlphaEdit silently becomes ridge-free MEMIT-like or no-op | D4 normalised moment; record dims; INVALID if ≈ 0 |
| Canonical-only fit | trained prompt improves, held-out doesn't | binding metric is held-out `para_full`; canon is diagnostic |
| Over-editing | behavior bought by damage | described-as locality, ≤ 5 pts |
| Window artefact | one window reproduces C10h's collapse | R1 `window_size=1` primary; R2 diagnostic |
| Model/hparams mismatch overread | 3B-base result read as official-7B | D3 listed; result labelled ported-3B-base |
| Aggregate-only | survivorship hidden | per-unit JSON; `experiment_gate.py check-result` |
| Baseline drift on new hardware | A7 "gain" vs a stale June baseline | R0 rerun in the same session on this machine |
