**The trap (D20, 2026-06-21, CORPUS/23):** D20 swept chunk **SIZE** C at fixed total N=100 to ask "does sub-batching reintroduce corruption?". But at fixed N, chunk-count **K = N/C** — so C=10 is *also* K=10. The corruption attributed to "smaller chunks" could equally be "more sequential update applications" (accumulated-update **COUNT** / cache_c accumulations), **not chunk size per se.** **The advisor reconcile pass DID flag the entanglement directionally** ("the design entangles chunk-COUNT with chunk-SIZE; at fixed N, #chunks ⟺ 1/chunk-size — you can't separate them; the spec lives at the size you didn't test") — it's why the pre-reg split component-1(scale)/component-2(chunking). The **cross-family promote-gate review (then gpt-5.5) SHARPENED it** into the precise causal-attribution confound (the corruption may be accumulated-update-**COUNT**, not size) + named the **2D N×C grid** disambiguator, and downgraded the verdict "falsifies condition 3" → "directional mechanism." So: **advisor surfaces the entanglement; cross-family sharpens the attribution + the remedy — complementary, run both.**

**Why it recurs here:** this program runs many **fixed-budget sweeps**. D1 did the same shape — concentration-vs-dilution at *fixed total-N=50* (sweeping same-relation count couples with other-relation count). Any "hold the total constant, vary the split" design has this structure: **size ↔ count, concentration ↔ dilution, depth ↔ breadth** are mechanically locked together once the budget is fixed.

**How to apply (binding, pre-registration checklist):**
- Before claiming a fixed-budget sweep **isolates** variable X: **write down every quantity your sweep mechanically co-determines** (the complement K=budget/X, the number of operations, accumulator updates, etc.). If any plausibly drives the metric, you have NOT isolated X.
- **Disentangle by design only where independent variation is possible:** an N×C grid cannot break count=N/C. Use equal-level contrasts to refute single-factor accounts and difference-in-differences to test interaction; name all still-coupled quantities and keep causal attribution scoped.
- **Reinforces [[codex-runs-inline-from-claude-bash]]:** run the **cross-family review (GPT-6-Astra since 2026-10-06) at every promote gate** — it *sharpens* directional flags the advisor raises into precise, named confounds + concrete disambiguating designs (it did so for both this K-vs-C confound and the B3N over-claims this session). Advisor and cross-family are **complementary** (entanglement-surfacing vs attribution-sharpening), not redundant — run both.
- Pairs with [[match-metric-to-the-claim]] (metric↔claim) — this is its IV-side twin (sweep-variable ↔ what's actually varying).

**Ext (C1-(a) K-vs-C, 2026-06-25, CORPUS/26, D-C1KVC-1) — a 2D grid does NOT break the confound when one factor is an IDENTITY of the other two.** The D20 follow-up ran the prescribed 2D N×C grid to break size-vs-count — but **count = N/C is an identity**, so there are only **2 free knobs (N,C)**; every cross-N contrast still moves two of {N,C,count}. The grid **rotated** the confound (size↔count → count↔N), it didn't eliminate it. Lessons that actually let you claim something:
  - To refute a "**depends only on X**" model, use **EQUAL-LEVEL contrasts** (its *defining* prediction: same X ⇒ same outcome; if two same-X cells differ, X-only is dead). A monotonicity-style contrast (lower-count cell less corrupt) does NOT refute a general f(count) — it only kills a *monotone* law. (Perplexity-Sonar cross-family caught this; advisor caught the identity.)
  - To show **interaction**, use **difference-in-differences** on the overlapping levels (N-effect at C=50 vs at C=10), not a 3-corner vignette. Different N-effects across C ⇒ non-additive ⇒ genuine interaction.
  - Refuting all single-factor + additive models is real and strong; but it does **NOT pin the functional form** (composite forms like N×g(C) survive) — say "rules out single-factor/additive," not "identified."
  - When the design literally can't break the identity (here: only 2 N-levels, pool capped at ~78 entities), say so and bank the *stimulus limit* itself as a finding/condition — don't contort the substrate (a fictional pool would have swapped the phenomenon).
