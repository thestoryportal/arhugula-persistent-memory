== Design decisions already made (MAESTRO) ==
R2, acyclic profiles (V4 F3): a profile's argv is a template. Where it needs its own hash, it holds the typed placeholder object {"$bind": "self_sha256"}, not a string. H = the canonical hash (F's hashing rule, unchanged) of the profile exactly as written, placeholder included. At launch the launcher renders argv by replacing each placeholder with H, and nothing else changes. Any other runtime-bound argument (for example a unit id) is also a typed placeholder {"$bind": "<name>"}, and the profile's `bindings` list must declare it, with the record and field that supply its value; an undeclared placeholder makes the profile invalid. A new immutable InvocationBinding receipt records profile_sha256, the rendered argv, rendered_argv_sha256 and each bound value with its source record hash. Consumers check the rendered argv against the template plus bindings before trusting a process. This applies to UnitProfile (executor and Intel invocations) and to the recovery LaunchProfile. Keep the round-4 executor order unchanged: suspended spawn → enrollment → coordinator CONSUME_UNIT → durable ACTIVE → SIGCONT (F:63,172,187).
R3, recovery outside the authority root (V4 F2): every recovery dependency moves to its own root R_rec, on a different physical device from the authority root R (memit, and the Development and backups volumes that share memit's disk, are excluded). R_rec holds the recovery executable copy, key, recovery LaunchProfile, enrollment journal and capture/evidence paths. The recovery sandbox reads R read-only (an unreadable or locked R is a recorded finding, not a wait), writes only R_rec/recovery/ (exclusive-create enrollment and evidence files), and holds no authority-writing capability. Fix the permission wording at F:119 versus F:190–191 so reads and writes agree. Restate F:244 to claim only what R_rec supports: recovery survives coordinator death, a blocked coordinator and an inaccessible R; if R_rec itself is unavailable, recovery refuses loudly and that case is OPEN with the reason. Why: the round-4 recovery path lived under the very root whose loss it was meant to survive.
R4 schema half, fencing variants (V4 F4): FencingReceipt becomes a discriminated union on `kind`:
- PRIOR_WRITER_CEASED: today's fields unchanged.
- NO_PRIOR_AUTHORITY (initial provisioning): no old_* fields at all (absent, not null). Evidence required: a raw observer capture hash showing R's authority store absent or empty, the disable-all record hash, and an independent quiescence capture hash.
- MISSING_HISTORY (prior authority existed, identities unrecoverable): no old_writer. Evidence required: disable-all record hash, independent quiescence capture hash, an unresolved_ownership marker, and a MAESTRO approval receipt hash. It never permits early replacement.
INITIALIZE and reconciliation accept exactly the variants each needs; state which in a v3 §4 table, with the C clause each relies on.
