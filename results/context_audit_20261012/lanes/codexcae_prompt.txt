## Verdicts (a row may carry two)
- KEEP: accurate, current, distinct.
- BLOAT: narrative, logs, history or detail that belongs in CORPUS/, the runbook, the checkpoint or git history, not in guidance. Give bytes and what to cut.
- CONFLICT: two sources give incompatible instructions or facts. Cite both sides and say which is current.
- DUPLICATE: the same rule or fact in two places. Name both; say which home should survive.
- NONFACTUAL: a claim the repo or the machine now contradicts.
- STALE: describes a state that has changed (status, next step, hardware, path, tool, model, threshold).
- AMBIGUOUS: two reasonable readings that lead to different actions. Quote the line and give both readings.
- MISLEADING: true alone but steers an agent wrong today.
- HISTORICAL: accurate record, no longer action-guiding (candidate to de-index or move).
- UNREACHABLE: guidance that no session actually loads, or a pointer to a missing file.
- FORMAT: memory frontmatter missing or invalid (`name`, `description`, `metadata.type`).
