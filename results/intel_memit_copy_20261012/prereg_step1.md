## Design (step 1)
1. **Population.** Regular files and symlinks under `SRC=/Volumes/memit/llm-database-poc-mirror/`. Excluded: the patterns in `tools/backup_mirror.excludes`; every `.hf_token`; `*/.git/objects/**/tmp_obj_*`; the tool's own state directory; and any file modified less than 10 minutes before the manifest started, because it may still be written (the next run picks it up). Credential-named files the scan finds are listed in the report for MAESTRO; none is admitted silently.
2. **Manifest first, on the M3.** A JSONL record per admitted path: relative path, kind, size, mtime_ns, inode, sha256 (or the symlink target). Built with native tools (`find`, `stat`, `/sbin/sha256sum`) under background priority. Resumable through a hash cache keyed by (path, size, mtime_ns, inode). Committed to git (gzip) with its own SHA-256.
3. **Transfer.** The M3 starts it. `rsync` over ssh on the cable (192.168.10.2, key `~/.ssh/intel_mac_ed25519`, `IdentitiesOnly=yes`) sends one representative path per digest the Intel does not already hold, into `~/memit_copy/incoming/` on the Intel. Background priority (`taskpolicy -b`, plus disk throttle if verified on the host).
4. **Science comes first.** The controller is a stdlib-only script on CLT Python 3.9. It calls `check_gpu()` in-process every 5 s. If it sees science, or the check fails, it ends the running hash or transfer child (process group SIGTERM, then SIGKILL after 5 s). It resumes after two consecutive clear polls. One exact exemption line in `tools/c10w_p2_gate.py` keeps the controller from blocking science's own gate. Its child tools (`rsync`, `ssh`, `sha256sum`, `find`, `stat`) do not match `COMPUTE_EXE`. **Stated plainly:** a science job that starts mid-copy can share the disk with the copy for up to one poll interval plus the stop time (~10 s) before the copy stops. Background priority covers that window. There is no advance process-list proof.
5. **The Intel verifies.** A stdlib Python 3.9 script, fed on stdin, re-hashes every received object. A match is published by rename to `objects/sha256/<digest>`, made read-only. It then builds `generations/<gen>/tree/<path>` as hard links (symlinks are recreated from the recorded target) and writes a receipt. A generation is COMPLETE only when every manifest entry is verified. A file that changed on memit after hashing makes the generation INCOMPLETE, and the next run recopies it. Mismatched bytes never become an object.
6. **Budgets, checked before any byte moves.** Intel recovery area (`~/memit_copy`, all objects, incoming and generation metadata) ≤ 250 GB (amendment 16). Intel free space after the projected new writes ≥ 80 GB floor + 20 GiB. memit receives only records (≤ 50 MB per generation). The M3 internal disk receives nothing. If a budget fails, the tool refuses before transferring and reports the deficit.

## Pass/fail criteria (numbered; tests derive from these)
- **P1 Build.** Unit tests are written first and pass under CLT Python 3.9. They cover population rules (each exclusion, the recent-file rule, symlinks), the manifest round-trip, duplicate digests sent once, resume after a killed hash and a killed transfer, the pause/resume state machine with an injected gate, budget boundaries (at, just inside and just outside each limit), the source-changed-after-hash path, a refused hash mismatch, receipt round-trip, py3.9 syntax, and exec bits.
- **P2 Real-scale manifest dry run** (MAESTRO's shell, no transfer). Completes on the real SRC. It reports files, bytes, distinct bytes and the credential-name scan. PASS needs distinct bytes ≤ 250 GB minus the space already used in the recovery area, and no credential-named file admitted.
- **P3 Pause control** (MAESTRO's shell, a small real subset to the Intel). A non-exempt sentinel (`python3 -c 'import time; time.sleep(60)'`) started mid-transfer makes the controller log PAUSED and stop its child within 10 s. After the sentinel exits, it resumes, and the subset's generation verifies COMPLETE.
- **P4 Full generation COMPLETE.** Every manifest entry is verified on the Intel, path counts are equal, and nothing extra appears. MAESTRO independently re-hashes, on the Intel, at least 200 randomly chosen objects plus the 20 largest, and reconciles total counts and sizes against the manifest.
- **P5 No route back.** After the copy, the Intel still holds no key, mount or login that reaches the M3. The copy wrote nothing on memit except repo records and the tool's state directory, and nothing on the M3 internal disk.
- **P6 Budgets held.** After P4, the recovery area is ≤ 250 GB and Intel free space is ≥ 80 GB.
- **P7 Science gate unaffected.** The exemption regex matches only the controller's exact command form (unit test, including near-miss negatives). On the host, `check_gpu()` called from a separate process while the controller runs reports no blocking process from the controller or its children.
- **P8 Review.** Astra (GPT-6-Astra, high) gives GO or GO-WITH-CONDITIONS on the code plus the P1-P3 evidence before the full copy (P4) starts. The verdict is committed next to this file.

**HALT:** an object hash mismatch that a re-stat of the source does not explain as a changed source, or any write outside the stated paths. Write a diagnostic, stop, and report. Budget refusal or an unreachable Intel: stop and report, with no retry loop.
